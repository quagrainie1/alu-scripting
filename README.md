# alu-scripting

A collection of scripting exercises covering regular expressions and API usage, used for grading and review purposes.

## Contents

- `api_advanced/` — Python scripts working with a public API (e.g. Reddit), including subscriber counts and recursive queries.
- `regular_expressions/` — Ruby scripts demonstrating various regex patterns and techniques.

## Usage

Each subdirectory contains its own scripts along with a `README.md` describing that section's exercises in more detail.
